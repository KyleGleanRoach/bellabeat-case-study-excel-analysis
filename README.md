# Bellabeat Case Study (Excel Analysis)

## Project Overview

This project is part of the Google Data Analytics Certificate and focuses on analyzing smart device usage data for Bellabeat, a wellness technology company. The goal is to identify trends in user behavior and provide data-driven recommendations to support marketing and business strategy.

## Purpose

The purpose of this analysis is to explore how consumers use smart fitness devices and uncover insights that can help Bellabeat improve customer engagement, product positioning, and marketing efforts.

## Key Features

* Data cleaning and preprocessing using Excel
* Exploratory Data Analysis (EDA)
* Use of pivot tables for trend analysis
* Data visualizations (charts and graphs)
* Business insights and recommendations

## Tools Used

* Microsoft Excel

## Key Insights

* Identified patterns in daily activity and usage behavior
* Highlighted opportunities for targeted marketing strategies
* Provided recommendations to enhance user engagement

## Files Included

* Excel workbook with full analysis
* Cleaned dataset
* Visualizations and charts
* Final case study report

## Conclusion

This project demonstrates the end-to-end data analysis process, from raw data to actionable insights, using Excel as the primary tool.
